# GraphQLQueryCostGate

**Local version 0.1.1. Author and maintainer: dhtfish98.** This is an independently written defensive lab, using a synthetic, loopback-only GraphQL service. It compares an intentionally weak no-budget baseline with a fixed pre-execution cost gate. It makes no claim that the studied upstream project has a vulnerability.

The fixed mode parses and validates one query, coerces variables, expands the selected operation's fragments, and estimates schema-weighted work. An aliased field contributes again; `first` multiplies its nested selection cost. The 120-unit budget is checked **before** GraphQL execution, so an over-budget request must produce zero resolver calls. For inputs that also fit the byte limits, fixed and baseline modes return the same data and resolver counts. Every synthetic resolver is counted.

The lab sets `first` to 1–10, query text to 16 KiB, variable JSON to 4 KiB, `tenant(id)` to 256 UTF-8 bytes, parser tokens to 2048, expanded selections to 4096, and selection nesting to 12. The complete serialized engine result and HTTP response body are each capped at 16 KiB. Oversized variables and IDs are rejected before resolvers; an oversized result is suppressed after execution, so it may still have nonzero resolver calls. Unknown schema fields and introspection fail closed in fixed mode. The HTTP server binds to `127.0.0.1`; weak mode is disabled unless `LAB_WEAK_BASELINE=1` is explicitly set for the lab.

From the repository root, run `node scripts/build.js`. It stages source, test/build scripts, and these documents under `Build/验证/GraphQLQueryCostGate`, records their hashes, installs the exact locked GraphQL-JS dependency, runs tests and four paired HTTP scenarios plus two resource-limit regressions, packs a source package, and installs that package in a separate consumer. The consumer probe runs from the frozen Build staging copy. Its JSON receipt prints the output path. Generated dependencies, caches, logs, packages, and results stay in `Build`.

To run only the loopback service from an installed package, use `node src/server.js` inside its installed package directory; it prints its assigned port. Send a JSON `POST /graphql` body with `query`, optional `variables`/`operationName`, and optional `mode`. The default is `fixed`. The baseline is solely for synthetic comparison.

The cost is a conservative estimate for the declared schema and weights, not a general GraphQL resource guarantee. Repeating the same fragment can be charged more than once even though GraphQL execution merges the resulting field; this can reject a query whose actual resolver count is below the numeric budget. The output cap acts after execution and is not a bound on peak memory. Subscriptions, mutations, real authorization, arbitrary custom resolvers, production data stores, batching, federation, and network deployment are outside this lab. Process peak RSS in the report is a process-wide high-water mark. A passing synthetic lab does not establish CVP applicant or project eligibility.
